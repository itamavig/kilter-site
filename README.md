# Kilter — support & privacy

The support page and privacy policy for **Kilter**, an iOS logic-puzzle game
by Itamar Avigdori.

- Support: https://itamavig.github.io/kilter-site/
- Privacy policy: https://itamavig.github.io/kilter-site/privacy.html
- Contact: slantpuzzle@icloud.com

Three static files, no build step. This repository is public only so that GitHub Pages
can serve these two pages — App Store Connect requires both a support URL and a privacy
policy URL, and both must be reachable without signing in. The app's own source is
private and is not here.
